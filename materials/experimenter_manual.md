# 实验员操作手册

## 实验概览

| 参数 | 数值 |
|------|------|
| 被试数 | 4 名高中生 |
| 实验条件 | A(主动翻转) / B(面朝上) / C(无手机) / D(被动翻转) |
| 重复次数 | 每条件 3 次 |
| 总数据点 | 4×4×3 = 48 |
| 每片段时长 | 25 分钟做题 + 2 分钟问卷 = 27 分钟 |
| 每人总时长 | 约 2 小时（含休息） |
| 建议周期 | 2 周内完成 |

---

## 准备工作（每次实验前）

1. **手机准备**：
   - 打开 PhoneFlipRitual App
   - 确认传感器权限已授权
   - 选择被试编号（S01-S04）和条件（A/B/C/D）
   - 检查电量 > 50%

2. **题目准备**：
   - 根据实验条件打印对应版本的题目（A版/B版/C版/D版）
   - 准备问卷打印件
   - 准备计时器（25分钟倒计时）

3. **环境准备**：
   - 安静房间，光线充足
   - 标准书桌，桌面平整
   - 手机放置在桌面固定位置（参与者正前方约20cm处）

---

## 四种条件的标准操作流程

### 条件 A：主动翻转朝下（仪式行为）

1. 实验员将手机**屏幕朝上**放置在桌面指定位置
2. 对被试说："这是你的手机，**请你把它翻过来，面朝下放好**，然后开始做题"
3. 观察并记录被试**自己动手翻转**的时刻
4. 被试开始做题，App 自动采集传感器数据
5. 25 分钟后铃声响起，被试停止做题，填写问卷

### 条件 B：面朝上正常放置（对照）

1. 实验员将手机**屏幕朝上**放置在桌面指定位置
2. 对被试说："这是你的手机，就放在这里，你可以开始做题了"
3. 被试开始做题，App 自动采集传感器数据
4. 25 分钟后铃声响起，被试停止做题，填写问卷

### 条件 C：手机不在桌上（无手机基线）

1. 实验员说："这是你的手机，**我把它拿到另一个房间去**，然后你开始做题"
2. 实验员将手机带出房间
3. 25 分钟后铃声响起，被试停止做题，填写问卷
4. **注意**：此条件下 App 不采集数据（或采集空数据标记条件C）

### 条件 D：被动翻转（实验者帮放 —— 控制仪式感的主体性）

1. 实验员将手机**屏幕朝上**放置在桌面指定位置
2. 对被试说："这是你的手机，**我来帮你把它翻过来**"
3. 实验员**亲自**将手机翻转为面朝下
4. 对被试说："好了，你可以开始做题了"
5. 被试开始做题，App 自动采集传感器数据
6. 25 分钟后铃声响起，被试停止做题，填写问卷

**关键点**：条件 A 和 D 的唯一区别是"谁执行了翻转动作"——这是研究"仪式感主体性"的核心实验操作。

## 注意事项

1. **标准化用语**：每次使用完全相同的指导语（见上方引号内容）
2. **不要暗示预期结果**：避免任何"这个条件应该会让你更专注"之类的表述
3. **片段间休息**：每个片段结束后给 3-5 分钟休息，每完成4个片段后给 15 分钟长休息
4. **数据备份**：每个片段结束后立即在 App 中导出 CSV 并命名标注
5. **记录异常**：如被试中途上厕所、手机滑落等事件，记在备注栏
6. **手机距离传感器**：确保手机面朝下时屏幕真的贴近桌面（如果有手机壳影响距离传感器，摘掉壳）
