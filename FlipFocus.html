FlipFocus
注意力仪式研究 · 传感器采集

📱 需要传感器权限

本实验需要访问设备的运动传感器和光线传感器来检测手机翻转状态。
不收集任何个人身份信息、位置或通信内容。

所有数据仅存储在浏览器本地，不上传云端

1
打开采集工具（10 秒）
用手机浏览器打开 FlipFocus.html 这个文件。
iOS：必须用 Safari 打开
Android：Chrome / Edge / 自带浏览器都可以
如弹出权限请求，点「授权」
2
校准传感器阈值（1 分钟）
切换到「采集」标签，把手机面朝下放在桌上：
· accZ 应显示约 -0.9 ~ -1.0g（若偏差大，调 Z 阈值）
· 光线值应 < 10 lux（若偏高，调光线阈值）
⚠ 每台手机第一次用都要校准！
3
开始实验片段（27 分钟/个）
在采集页面设置：被试编号 + 实验条件 + 第1/2次，
然后点「开始采集」，倒计时 25 分钟后自动结束。
每人 4 个条件 × 2 次重复 = 8 个片段
四种实验条件（每人全做，每种 2 次 = 每人 8 个片段，4人共 32 片段）
条件谁翻手机？手机在哪？指导语
A 主动翻转 学生自己 面朝下 "请你自己把手机翻过来，然后开始做题"
B 面朝上 不翻 面朝上 "手机就放这里，你开始做题"
C 无手机 - 拿走 "我把手机拿到另一个房间去"
D 被动翻转 实验员帮翻 面朝下 "我来帮你翻，好了，你开始做题"
⭐ A 和 D 的唯一区别是"谁动手"——这是整个研究的核心问题
4
导出数据
时间到后震动提醒，点「导出数据」下载 1 个文件：
xxx_bundle.json 包含传感器数据 + 翻转事件 + 实验信息
（所有数据打包在一个文件里，微信直接发给实验员即可）
5
分析数据
全部 32 个片段采集完后，把 data 文件夹拷到电脑：
cd analysis
pip install -r requirements.txt
python 01_preprocess.py --data-dir ../data/
python 02_analysis.py
python 03_visualize.py
实验进度检查清单
点击勾选，进度保存在浏览器中
⚠ 关键提醒
· 每人 4 条件 × 2 次 = 8 个片段，4 人共 32 个
· 每个片段结束立刻导出，不要攒到最后
· 做题用打印的题目纸，手机只负责采集传感器
· 条件 A 和 D 指导语必须严格区分
· Day1 全天采集，Day2 分析+写论文
