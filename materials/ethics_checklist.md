# 伦理合规检查清单

> 投稿前必须全部确认为 ✅

---

## 被试保护

- [ ] 4 名被试均签署知情同意书（**未成年人必须有监护人签字**）
- [ ] 实验方案经指导老师/学校口头认可（Teenager Show 无正式 IRB 要求，但论文中需声明）
- [ ] 被试可在任何时间退出，无需说明理由
- [ ] 退出后，对应的数据立即删除

## 数据安全

- [ ] 所有传感器数据存储在手机本地，**不上传任何云端服务器**
- [ ] 数据仅包含加速度计和光线传感器读数，**不含 GPS/通信内容/个人身份信息**
- [ ] CSV 文件传输到分析电脑使用 USB 有线连接（不用微信/邮件/网盘）
- [ ] 分析完成后，手机上的原始数据建议删除

## 匿名化

- [ ] 论文中使用 P1-P4 代替被试真实姓名
- [ ] 不暴露学校名称（可用"a high school in [城市名]"）
- [ ] 原始数据不公开发布（可注明"data available upon reasonable request"）

## 论文声明

- [ ] 论文中明确包含伦理实践声明段（见 consent_form.md 末尾模板）
- [ ] 论文中明确声明"本研究为探索性试点，n=4，结果不具统计推广性"
- [ ] 论文中注明研究获得指导老师/学校认可

## 利益冲突

- [ ] 被试不包含研究者本人（如研究者也是高中生，不能自己做被试）
- [ ] 被试不因参与实验而获得任何学业成绩上的利益
- [ ] 实验期间不给被试任何关于预期结果的暗示
