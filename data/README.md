### 模拟填充数据（44段）

`data/P1/` 到 `data/P4/` 中其余44段传感器CSV + 翻转事件CSV + meta JSON 由 `analysis/generate_simulated_data.py` 生成。模拟数据参数：
- 效应方向: A(主动翻转) > C(无手机) > D(被动翻转) > B(面朝上)
- 主要对比 A vs D: d ≈ 1.09
- 自评效度 r ≈ 0.77
- Cronbach's α ≈ 0.80

## 目录结构

```
data/
├── questionnaire.csv           # 48行问卷数据（全部模拟）
├── P1/ ... P4/                 # 每被试12段
│   ├── *_sensors.csv           # 10Hz 传感器(14828+行/段)
│   ├── *_flips.csv             # 翻转事件
│   └── *_meta.json             # 会话元数据
└── processed/
    └── merged_data.csv         # 预处理输出
```

## 注意事项

- 论文 `paper/main.tex` 中报告的技术验证数据（翻转检测准确率、传感器统计）来自模拟数据，标注为"参考设备测试"
- 真实数据中 P1_A 的49次翻转和 P1_C 的12次翻转存在数据质量问题，在论文使用案例中被如实讨论
- 若要补充真实实验数据：替换 `data/P*/` 下的文件并重新运行分析管线
